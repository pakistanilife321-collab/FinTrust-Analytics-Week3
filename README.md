# FinTrust Digital Bank — Week 3 Analytics & Validation

This repository contains the Week 3 deliverables for the FinTrust Digital Bank assessment.

## 📂 Repository Contents
- **`Week3_Analysis_and_Validation.ipynb`**: Python notebook for RFM customer segmentation and data quality assertions.
- **`Week3_Advanced_Queries.sql`**: SQL scripts featuring multi-dimensional CTEs, $NTILE$, and $DENSE\_RANK$ window functions.
- **`Week3_Documentation.docx`**: Comprehensive report with validated findings, KPI analysis, and management recommendations.

## 🛠️ Tools Used
- **SQL (PostgreSQL)**: CTEs, Window Functions, Data Auditing
- **Python**: Pandas, NumPy, Matplotlib, Seaborn
- **Power BI**: Star Schema Data Modeling, DAX Time Intelligence
